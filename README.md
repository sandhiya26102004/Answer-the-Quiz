# 📝 Answer the Quiz

This is a simple web-based quiz project built with **HTML** and **JavaScript**. It presents a single question:  
> ❓ _"What is the capital of India?"_

Users can select one of the multiple-choice options and get immediate feedback upon submission.

---

## 🚀 Features

- ✅ Single question multiple-choice quiz
- ✅ Instant result feedback on submit
- ✅ Message cleared when user changes their answer
- ✅ Clean separation of HTML and JS (Thaniya-style)
- ✅ Beginner-friendly code
